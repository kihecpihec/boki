Full upgrade pool and eligibility

XP thresholds: 3 → 7 → 12 → 18 → 25 → 33 cumulative packs. Roughly three selections in an ordinary run; five or six require risky stays.

  • Rave Overdrive: +30% original base damage, cap 3.
  • Turbo Skiro: +20% original base riding speed, cap 2; boost speed unchanged.
  • Bigger Battery: +40% original base capacity, cap 2; preserve charge percentage (100 → 140 → 180 capacity).
  • Double Trouble: second full-damage instantaneous hit per firing cycle, cap 1; another valid target preferred, otherwise original still-living target; respect occlusion.
  • Panic Mode: boost modifier above, cap 1. PANIC READY requires ownership and active chase within 10 m.
  • Emergency Snack: repeatable while injured. Battery Charge recovery: only below capacity.

Remove capped/ineligible offers. Resolve multiple thresholds sequentially without resuming combat. All bonuses add original base percentages.

The paused offer is a state example, not a live selection. No boost, charge, warning or upgrade behavior is implemented by these mocks.
